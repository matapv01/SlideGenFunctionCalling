Cách sử dụng SlideGen
1
Upload tài liệu
Chọn và tải lên file Word (.docx) chứa nội dung bài thuyết trình của bạn.
2
Xử lý tự động
Hệ thống AI sẽ phân tích nội dung và tự động tạo ra các slide phù hợp.
3
Chỉnh sửa
Sử dụng editor để tùy chỉnh layout, màu sắc, font chữ theo ý muốn.
4
Xuất file
Tải về bài thuyết trình dưới dạng HTML, PDF hoặc PowerPoint.
