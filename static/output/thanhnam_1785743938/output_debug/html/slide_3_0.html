2. Phương pháp được đề xuất

01
Kiến trúc tổng thể:
• Thành phần chính:
Large Language Model (LLM) - Xử lý nội dung và tạo slide
Vision‑Language Model (VLM) - Đánh giá chất lượng slide
HTML Functions Library - Thư viện các hàm tạo ra các mẫu slide khác nhau
02
Kiến trúc hệ thống:
1. Tiền xử lý:
- Tải tài liệu (PDF/DOCX)
- Kỹ thuật chunking phân tách nội dung
- Tạo danh sách nội dung cho từng slide
2. Xử lý LLM:
- Đọc hiểu, phân tích, tóm tắt nội dung
- Lựa chọn mẫu HTML/CSS phù hợp
- Function Calling tạo slide hoàn chỉnh
- Điều chỉnh yếu tố thẩm mỹ (màu sắc, font, bố cục)
3. Function Calling:
- Tích hợp các hàm để sinh slide
